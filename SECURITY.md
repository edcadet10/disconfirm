# Security policy

## Supported version

The latest commit on `main` is supported. Older snapshots do not receive
separate security backports.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/edcadet10/disconfirm/security/advisories/new).
Do not disclose a suspected vulnerability in an issue, Discussion, or pull
request.

Useful reports include a minimal reproduction, affected commit, realistic
impact, and any suggested mitigation. Use fictional or redacted inputs; do not
include credentials, private prompts, or proprietary evidence.

Relevant reports include unexpected installer writes, hook execution or output
that can block prompt submission, unsafe instruction injection, and handling of
malformed hook input.
